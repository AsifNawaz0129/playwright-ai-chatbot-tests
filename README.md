## Setup and Running Tests

This project uses Playwright for end-to-end testing.

1.  **Install dependencies:**
    ```bash
    npm install
    ```

2.  **Install Playwright browsers:**
    ```bash
    npx playwright install
    ```

3.  **Run tests:**
    ```bash
    npx playwright test
    ```
